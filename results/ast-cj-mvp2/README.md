# Персональный ИИ-ассистент для заметок и напоминаний — MVP v2

Вторая версия Telegram-бота «Склерозник». Принимает произвольные фразы на русском
(«напомни завтра в 10 позвонить в банк», «запомни ссылку про ssh»), раскладывает
их по структуре и потом находит по запросу на естественном языке. Работает
полностью локально: данные не покидают домашний сервер.

## Что изменилось относительно первой версии

Проект развивается; вторая версия касается того, что чаще всего мешало
в повседневном использовании, — поиска и разбора времени.

**Поиск.** В первой версии был подстрочный поиск по тексту. Во второй запрос
разбирается моделью: определяются ключевые слова и фильтр (дела, ссылки,
отложенное, напоминания), а поиск идёт по полнотекстовому индексу SQLite
(FTS5, токенизатор `trigram`) с ранжированием и расширением по словарю
концептов. Появилась возможность отвечать на запросы вида «список ссылок»
и «что отложено почитать», которые раньше не находили нужного.

**Модель данных.** Вместо пяти типов и десяти подтипов — три типа
(`note / task / event`) и один флаг «руководство». Напоминание и ссылка стали
атрибутами, а не типами: событие со ссылкой больше не требует
взаимоисключающего выбора.

**Разбор времени.** Модель извлекает структуру («16 сентября», «за 3 дня»,
«в пятницу»), дату вычисляет код. На наборе из 26 фраз — 26 верных;
у прежнего подхода на `dateparser` — 17.

**Данные.** Записи первой версии (63) мигрированы, время пересчитано.

## Результаты замеров

Методика простая: эталонный набор из реальных записей, замер до и после.

| Что проверялось | До | После |
|---|---|---|
| «это дело»: precision / recall | 0.52 / 0.61 | 1.00 / 1.00 |
| «это руководство»: precision / recall | 0.50 / 0.90 | 0.91 / 1.00 |
| разбор времени, верных из 26 | 17 | 26 |
| запрос «список ссылок» | последние записи, без фильтра | все 37 |

Точность классификации по типу — 63 из 63 на эталонном наборе; из них две записи
исправлены не моделью, а правилом в коде.

## Стек

Python 3.12, `python-telegram-bot`, SQLite + FTS5, APScheduler,
локальная модель `gemma4:e4b-it-q4_K_M` через Ollama, systemd на Ubuntu.
